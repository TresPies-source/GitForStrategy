# Fabricate Nothing

*Say "not measured," and say how you would measure it.*

## What it is

No invented numbers. Where the evidence is thin, say it is unmeasured, and describe the measurement that would settle it.

## Why it matters

A reader forgives "we don't have the number yet; here is how we will get it." A reader who finds one invented number stops trusting all the others.

## The pattern

1. For every number, name its source.
2. If there is none, write "not measured."
3. Describe the measurement that would produce it: what is compared, against what baseline, decided before the run.
4. Publish the result when it exists, a null result included.

## Revisit when

You write anything public. A number appears in a status file.

## What it refuses

Benchmarks without baselines, and percentages without sources.

## Grew from

A 2026 launch-positioning scout in the Dojo Genesis practice. And Git for Strategy's own history: its first release led with outcome numbers that were never measured against a baseline. Version 2.0.0 removed them.
